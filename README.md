# NutriTrack – Nutrition Tracker App

NutriTrack is an Android nutrition tracking app built with Kotlin and Jetpack Compose. It helps users monitor their daily food intake, calories, water consumption, and nutrition goals.

## Features

- Track daily food intake
- Monitor calories
- Track daily water consumption
- View nutrition history and analytics
- Manage user profile and nutrition goals

## Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Database:** Room
- **Build System:** Gradle
- **Platform:** Android

## Getting Started

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Run the app on an Android emulator or compatible device.

## Project Status

This project is intended to help users track their daily nutrition and build healthier habits.
